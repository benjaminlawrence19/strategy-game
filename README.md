# Strategy Game – Computer Science NEA

A JavaScript strategy game developed as part of my A-level Computer Science coursework.

## Overview

The project involved designing, developing and testing an interactive strategy game. The development process included translating requirements into working functionality, identifying and resolving software bugs, and refining the game through stakeholder feedback.

## Development

- **Requirements analysis:** Identifying the intended functionality and translating requirements into a working application.
- **Game development:** Implementing the game using JavaScript.
- **Iterative development:** Refining functionality and making improvements throughout the development process.
- **Stakeholder feedback:** Gathering feedback from a stakeholder acting as a bug tester and using it to guide further development.
- **Problem-solving:** Investigating reported issues, correcting bugs and improving the application.

## Testing

Testing was incorporated throughout development. Feedback from a stakeholder helped identify errors, which I investigated and corrected. Other suggestions were considered and incorporated into subsequent iterations.
